# UltraPermissions

Керування правами, групами та рангами Minecraft за допомогою команд і графічного редактора. **5.6.11** додає сповіщення про оновлення через GitHub Releases й усуває залишкові прогалини перекладу російського та українського інтерфейсу, зберігаючи виправлення безпеки й сумісності.

Ми підготували самостійний Gradle-проєкт, зберегли основні можливості керування правами, переробили небезпечні мережеві та SQL-шляхи й додали негативні тести безпеки. У цій версії усунуто вісім раніше виявлених проблем рівнів HIGH/MEDIUM і додатково посилено авторизацію адміністративних команд.

Це виправлення вразливостей застосунку. Перевірка не встановила наявності вірусів або навмисної шкідливої закладки, тому ми не заявляємо про «видалення вірусів» чи абсолютну безпеку.

## Можливості

- Індивідуальні права та групи: дозволи, заборони `-permission.node`, шаблони прав і успадкування.
- Кілька груп у гравця, пріоритети, тимчасове надання груп і прав, автоматичне завершення строку дії.
- Області дії за світом і сервером, зокрема окремі права для BungeeCord.
- Графічні редактори користувачів, груп, прав і ланцюжків рангів, піктограми та налаштування відображення.
- Префікси, суфікси, кольори, основний/додатковий ранг і таймери рангів.
- Підвищення та пониження за налаштовуваними Group Paths.
- Делеговане надання дозволених груп з обмеженням строку дії.
- Локальне JSON-сховище або MySQL, синхронізація з підписом між довіреними вузлами.
- Інтеграції з Vault, PlaceholderAPI, MVdWPlaceholderAPI та NametagEdit.
- Перенесення з LuckPerms/PermissionsEx, копіювання груп, перенесення облікових записів і сховищ File/MySQL.
- Вбудовані офлайн-переклади російською та українською (по 805 рядків інтерфейсу й 159 назв сутностей), довідкова база вузлів прав і журнал перевірок прав.

## Завантаження та встановлення

1. Завантажте **UltraPermissions-5.6.11.jar** з розділу [Випуски](https://github.com/slyphmp4/UltraPermissions/releases). Файл `-sources.jar` на сервер не встановлюється.
2. Помістіть JAR у `plugins`, приберіть іншу копію UltraPermissions із цієї папки та перезапустіть сервер.
3. Для початку адміністрування виконайте **з консолі** `upc AddSuperAdmin ВашНік`, коли гравець уже приєднався та має запис користувача, а потім відкрийте `/uperms`.
4. Для мережі або MySQL дотримуйтеся [інструкції налаштування](docs/CONFIGURATION.uk.md). Усі вузли мають використовувати цю версію з виправленнями безпеки.

**Minecraft Java Edition: сумісність до 26.2.** Paper 26.2 / Java 25 проходить ізольовані перевірки під час виконання. Попередні версії серверів і підтримку проксі описано в [матриці сумісності](docs/COMPATIBILITY.uk.md). Класи застосунку мають цільовий рівень Java 17; збирання використовує JDK 21. Версія 5.6.11 — стабільний випуск спільноти.

## Збирання в IntelliJ IDEA

Відкрийте папку як Gradle-проєкт, виберіть **Gradle Wrapper** і **JDK 21** для Gradle JVM.

```powershell
.\gradlew.bat clean build --offline
```

Linux/macOS:

```sh
bash ./gradlew clean build --offline
```

Під час першого запуску Wrapper завантажує Gradle 8.14.5 з перевіркою SHA-256. Залежності плагіна зафіксовано в `libs`; після завантаження дистрибутива Wrapper збирання не потребує зовнішнього Maven-репозиторію. Готові JAR містяться в `build/libs`.

## CI та перевірка компонентів

GitHub Actions виконує чисте збирання на **Ubuntu і Windows / JDK 21**. `verifyComponents` перевіряє хеші залежностей, склад JAR, відсутність серверних API й тестових класів у плагіні, ресурси, версію, цільовий рівень Java та **7085 контрактів API**. `verifySecurityFixes` перевіряє підроблення й повторне надсилання повідомлень, зв'язування параметрів SQL, відмову пулу, сеанси GUI, кодеки предметів, політику TLS та адміністративні гілки команд. Мережеві з'єднання й запуск системних процесів у тестовій JVM заблоковано.

Окрема перевірка запускає плагін на **Paper 26.2 / Java 25** у Docker та виконує **14 перевірок під час виконання**. Плагін не має доступу до зовнішньої мережі. Див. [межі перевірки та кроки відтворення](docs/COMPATIBILITY.uk.md). Тег `v<version>` створює стабільний випуск лише після успішного збирання на обох ОС і перевірки на сервері. Файли випуску: JAR плагіна, JAR вихідного коду, повний Gradle-проєкт та контрольні суми SHA-256.
