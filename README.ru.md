# UltraPermissions

Управление правами, группами и рангами Minecraft через команды и оригинальный GUI TechsCode. **5.6.20** добавляет совместимость с Folia 26.3. См. [изменения выпуска](docs/releases/5.6.20.ru.md).

Если настроенное хранилище прав недоступно, запуск сервера/прокси теперь останавливается с инструкцией восстановления. Независимые уведомления об обновлениях и проверенная загрузка из GitHub сохранены.

Это исправления безопасности и надёжности приложения без обещания абсолютной безопасности или «удаления вирусов».

## Возможности

- Индивидуальные права и группы: разрешения, запреты `-permission.node`, шаблоны прав и наследование.
- Несколько групп у игрока, приоритеты, временная выдача групп и прав, автоматическое истечение сроков.
- Области действия по миру и серверу; отдельные права для BungeeCord.
- GUI для пользователей, групп, разрешений и цепочек рангов; иконки и настройки отображения.
- Префиксы, суффиксы, цвета, основной/дополнительный ранг и таймеры рангов.
- Повышение/понижение по настраиваемым Group Paths.
- Делегированная выдача разрешённых групп с ограничением времени выдачи.
- Локальное JSON-хранилище или MySQL; подписанная синхронизация между доверенными узлами.
- Интеграции Vault, PlaceholderAPI, MVdWPlaceholderAPI и NametagEdit.
- Перенос данных из LuckPerms/PermissionsEx, копирование групп, перенос аккаунтов и перенос хранилищ File/MySQL.
- Встроенные офлайн-переводы на русский и украинский (по 852 строк интерфейса и 159 названий существ), справочная база узлов прав и журнал проверки прав.

## Скачать и установить

1. Скачайте **UltraPermissions.jar** из [Релизы](https://github.com/slyphmp4/UltraPermissions/releases). `UltraPermissions-sources.jar` на сервер не устанавливается.
2. Поместите JAR в `plugins`, убрав другую копию UltraPermissions из той же папки, затем перезапустите сервер.
3. Для начала администрирования выполните **из консоли** `upc AddSuperAdmin ВашНик`, когда пользователь уже зарегистрирован после входа, затем откройте `/uperms`.
4. Для сети или MySQL следуйте [инструкции настройки](docs/CONFIGURATION.ru.md). Все узлы должны использовать эту security-версию.

**Minecraft Java Edition: совместимость до 26.3.** Один JAR плагина проверяется на Paper 1.20.1, 1.20.6, 1.21.11, 26.1.2, 26.2, 26.3, Folia 26.3 с подходящей Java 17, 21 или 25. Предыдущие версии серверов и поддержка прокси описаны в [матрице совместимости](docs/COMPATIBILITY.ru.md). Классы приложения имеют целевой уровень Java 17; сборка использует JDK 21. Это исходный код версии 5.6.20; актуальные опубликованные стабильные выпуски доступны в GitHub Releases.

## Собрать в IntelliJ IDEA

Откройте папку как Gradle-проект, используйте **Gradle Wrapper** и **JDK 21** в Gradle JVM.

```powershell
.\gradlew.bat clean build --offline
```

Linux/macOS:

```sh
bash ./gradlew clean build --offline
```

Первый запуск Wrapper скачивает Gradle 8.14.6 с проверкой SHA-256. Зависимости плагина закреплены в `libs`, после загрузки Wrapper сборка не требует внешнего Maven-репозитория. Готовые JAR находятся в `build/libs`.

## CI и проверка компонентов

GitHub Actions запускает чистую сборку на **Ubuntu и Windows / JDK 21**. `verifyComponents` проверяет SHA зависимостей, состав JAR, отсутствие серверных API и тестовых классов в плагине, ресурсы, версию, целевой уровень Java и **7085 контрактов API**. `verifySecurityFixes` проверяет подделку/повтор сообщений, связывание параметров SQL, отказ пула, сессии GUI, кодеки предметов, политику TLS и административные ветки команд. Сеть и системные процессы в тестовой JVM заблокированы.

Отдельная проверка запускает один и тот же JAR на шести закреплённых версиях Paper и **Folia 26.3** в Docker. Два локальных клиента проверяют навигацию по меню, ввод через чат и права в разных регионах Folia. Тестовые контейнеры работают без внешней сети. См. [матрицу совместимости](docs/COMPATIBILITY.ru.md). Тег `v<version>` запускает CI релиза, который после успешных проверок прикрепляет JAR, исходники, полный проект и контрольные суммы SHA-256.
