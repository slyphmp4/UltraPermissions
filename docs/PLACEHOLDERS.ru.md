# Интеграции и плейсхолдеры

Vault обеспечивает интеграцию прав/чата; PlaceholderAPI и MVdWPlaceholderAPI предоставляют данные совместимым плагинам. NametagEdit обслуживает отображение имён/префиксов при наличии интеграции. Устанавливайте эти плагины отдельно, когда они нужны; API-файлы compile-only из проекта исходников копировать на сервер не нужно.

## PlaceholderAPI

Идентификатор: `uperms`. Базовые плейсхолдеры:

| Плейсхолдер | Назначение |
|---|---|
| `%uperms_prefix%` | Префикс игрока или первой группы |
| `%uperms_prefix_color%` | Цвет префикса игрока или первой группы |
| `%uperms_prefixes%` | Префикс игрока вместе с префиксами групп |
| `%uperms_rank%` | Имя первой группы |
| `%uperms_rank_timer%` | Таймер следующей по приоритету временной группы |
| `%uperms_rank_timer_detailed%` | Подробный таймер следующей по приоритету временной группы |
| `%uperms_ranks%` | Имена всех групп |
| `%uperms_secondaryprefix%` | Префикс второй группы |
| `%uperms_secondarysuffix%` | Суффикс второй группы |
| `%uperms_suffix%` | Суффикс игрока или первой группы |
| `%uperms_suffix_color%` | Цвет суффикса игрока или первой группы |
| `%uperms_suffixes%` | Объединённые суффиксы всех групп |

Встроенный формат шаблонов плагина — `{Prefix}`, `{Rank}`, `{Rank_timer}` и соответствующие имена из списка, с учётом места использования. Запрос PlaceholderAPI должен иметь контекст пользователя; значения зависят от мира/сервера и действующих групп.

Дополнительные формы запросов обработчика: `has_group_<group>`, `has_permission_<node>`, `permission_timer_<node>`, `inherits_group_<group>`, `rank_timer_<group>`. Они требуют существующего пользователя/объекта; плагин интеграции задаёт контекст запроса. Полное окружение Minecraft/плейсхолдеров не запускается в офлайн CI.
