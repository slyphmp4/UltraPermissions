# Інтеграції та плейсхолдери

Vault забезпечує інтеграцію прав/чату; PlaceholderAPI та MVdWPlaceholderAPI надають дані сумісним плагінам. NametagEdit обслуговує відображення імен/префіксів за наявності інтеграції. Установлюйте ці плагіни окремо, коли вони потрібні; API-файли compile-only із проєкту вихідного коду копіювати на сервер не потрібно.

## PlaceholderAPI

Ідентифікатор: `uperms`. Базові плейсхолдери:

| Плейсхолдер | Призначення |
|---|---|
| `%uperms_prefix%` | Префікс гравця або першої групи |
| `%uperms_prefix_color%` | Колір префікса гравця або першої групи |
| `%uperms_prefixes%` | Префікс гравця разом із префіксами груп |
| `%uperms_rank%` | Ім'я першої групи |
| `%uperms_rank_timer%` | Таймер наступної за пріоритетом тимчасової групи |
| `%uperms_rank_timer_detailed%` | Докладний таймер наступної за пріоритетом тимчасової групи |
| `%uperms_ranks%` | Імена всіх груп |
| `%uperms_secondaryprefix%` | Префікс другої групи |
| `%uperms_secondarysuffix%` | Суфікс другої групи |
| `%uperms_suffix%` | Суфікс гравця або першої групи |
| `%uperms_suffix_color%` | Колір суфікса гравця або першої групи |
| `%uperms_suffixes%` | Об'єднані суфікси всіх груп |

Вбудований формат шаблонів плагіна — `{Prefix}`, `{Rank}`, `{Rank_timer}` та відповідні імена зі списку, залежно від місця використання. Запит PlaceholderAPI повинен мати контекст користувача; значення залежать від світу/сервера й активних груп.

Додаткові форми запитів обробника: `has_group_<group>`, `has_permission_<node>`, `permission_timer_<node>`, `inherits_group_<group>`, `rank_timer_<group>`. Вони потребують наявного користувача/об'єкта; плагін інтеграції задає контекст запиту. Повне середовище Minecraft/плейсхолдерів не запускається в офлайн CI.
