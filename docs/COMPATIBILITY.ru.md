# Совместимость с Minecraft до 26.3

Один **UltraPermissions.jar** проверяется на каждой закреплённой сборке Paper ниже. Для каждой выполняются две успешные загрузки и отдельный запуск с отказавшим настроенным хранилищем: выдача и запрет прав, наследование, пути рангов, профили голов, метаданные локализованного GUI обновлений, сохранение данных и стандартная папка обновлений.

| Версия Paper | Сборка | Java |
|---|---|---|
| 1.20.1 | 196 | 17 |
| 1.20.6 | 151 | 21 |
| 1.21.11 | 132 | 21 |
| 26.1.2 | 74 | 25 |
| 26.2 | 135 | 25 |
| 26.3 | 253 | 25 |

Загрузки серверов, SHA-256 и контрольные суммы контейнеров Java закреплены в [paper-targets.json](../config/paper-targets.json). CI проверяет, что все шесть отчётов относятся к одному и тому же JAR плагина; отсутствие или ошибка любой версии блокирует выпуск. На Paper 26.2 и 26.3 дополнительно выполняется синтетический нагрузочный тест: 512 профилей и минимум 400 000 проверок прав.

| Другая платформа | Область совместимости |
|---|---|
| Предыдущие Bukkit/Spigot/Paper 1.13–1.21.11 | Прежние цели совместимости сохранены; проверяется не каждая промежуточная версия. Нужна Java 17 или более новая по требованиям сервера. |
| BungeeCord | Компиляция с 1.21-R0.4; полного теста настоящего прокси нет. Минимум Java 17. |
| Velocity / Folia / Cardboard / Fabric | Плагин прокси Velocity не поддерживается; остальные реализации требуют отдельной проверки. Для Fabric нужен слой совместимости Bukkit, например Cardboard. |

Тест использует подмены Player/CraftPlayer и не имитирует подключённого клиента, все действия в меню, настоящее согласование MySQL TLS или все сочетания интеграций. Vault, PlaceholderAPI, MVdWPlaceholderAPI и NametagEdit подключаются при наличии совместимого провайдера. Отрисовка у клиента и настоящий сервер Cardboard требуют отдельных ручных проверок.

Версия исходного кода: 5.6.19. Сборка: Gradle 8.14.6 / JDK 21; целевой байткод приложения: Java 17. API компиляции остаётся Spigot 1.21.11, а `api-version: 1.13` задаёт базовый API и не доказывает работу каждой версии.

При отказе настроенного MySQL сервер/прокси останавливается без загрузки старых локальных прав. Каждый запуск с отказом проверяет сохранность локальных файлов прав.

```sh
python tools/verify_paper.py --paper-version 26.3 --plugin build/libs/UltraPermissions.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime-26.3 --report-dir build/reports/runtime --accept-eula
```

Выберите другую закреплённую версию через `--paper-version` и используйте новую рабочую папку. Флаг принимает Minecraft EULA для одноразового сервера. Порты контейнера не публикуются; плагины работают без сети. Доступ к сети имеет только закреплённый загрузчик Paper при подготовке зависимостей.

Выпуски включают `runtime-verification.json` для 26.3 и `compatibility-verification.json` для всей матрицы.
