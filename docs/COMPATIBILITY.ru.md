# Совместимость с Minecraft до 26.2

Целевая платформа выпуска — Paper 26.2 / Java 25. Проверка включает две успешные загрузки и отдельный запуск с отказавшим настроенным хранилищем (42 утверждения), проверку метаданных голов, сохранение данных и стандартную папку обновлений.

Предыдущие Bukkit/Spigot/Paper остаются целями совместимости; полной матрицы запусков нет. api-version: 1.13 задаёт базовый API, а не подтверждает работу каждой промежуточной версии.

| Сервер | Java | Проверка |
|---|---|---|
| Paper 26.2 build 135 | 25 | Сохранение, ранги, метаданные, переводы, обновления и остановка при отказе MySQL. |
| Bukkit/Spigot/Paper 1.13–1.21.11 | Минимум 17 и требования самого сервера | Компиляция со Spigot 1.21.11; полной матрицы запусков нет. |
| BungeeCord | Минимум 17 | Компиляция с 1.21-R0.4; полного теста настоящего прокси нет. |
| Velocity / Folia / Cardboard / Fabric | Зависит от платформы | Плагин прокси Velocity не поддерживается; другие реализации требуют отдельной проверки. |

Тест использует подмены Player/CraftPlayer и не имитирует подключённого клиента, настоящее согласование MySQL TLS или все сочетания интеграций. Vault, PlaceholderAPI, MVdWPlaceholderAPI и NametagEdit подключаются при наличии совместимого провайдера.

Версия исходного кода: 5.6.16. Сборка: Gradle 8.14.6 / JDK 21; целевой байткод приложения: Java 17. Отдельный нагрузочный тест использует 512 синтетических профилей и минимум 400 000 проверок прав; это не тест подключённых игроков.

При отказе настроенного MySQL сервер/прокси останавливается, не загружая старые локальные права. Отдельный запуск проверяет сохранность локальных файлов прав.

```sh
python tools/verify_paper.py --plugin build/libs/UltraPermissions.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime-5616 --report-dir build/reports/runtime --accept-eula
```

Для каждого запуска используйте новую рабочую папку. Флаг принимает Minecraft EULA для одноразового тестового сервера. Порты контейнера не публикуются; плагины запускаются без сети. Доступ к сети есть только у закреплённого загрузчика Paper при подготовке зависимостей.
