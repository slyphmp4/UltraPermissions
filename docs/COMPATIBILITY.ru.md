# Совместимость с Minecraft до 26.3

Один **UltraPermissions.jar** проверяется на каждой закреплённой сборке ниже. Для каждой выполняются две успешные загрузки и отдельный запуск с отказавшим настроенным хранилищем: выдача и запрет прав, наследование, пути рангов, профили голов, метаданные локализованного GUI обновлений, сохранение данных и стандартная папка обновлений.

| Сервер | Сборка | Java |
|---|---|---|
| Paper 1.20.1 | 196 | 17 |
| Paper 1.20.6 | 151 | 21 |
| Paper 1.21.11 | 132 | 21 |
| Paper 26.1.2 | 74 | 25 |
| Paper 26.2 | 135 | 25 |
| Paper 26.3 | 253 | 25 |
| Folia 26.3 | 28 | 25 |

Загрузки серверов, SHA-256 и контрольные суммы контейнеров Java закреплены в [paper-targets.json](../config/paper-targets.json) и [folia-targets.json](../config/folia-targets.json). CI проверяет, что все семь отчётов относятся к одному и тому же JAR плагина; отсутствие или ошибка любой версии блокирует выпуск. На Paper 26.2 и 26.3 дополнительно выполняется синтетический нагрузочный тест: 512 профилей и минимум 400 000 проверок прав.

| Другая платформа | Область совместимости |
|---|---|
| Предыдущие Bukkit/Spigot/Paper 1.13–1.21.11 | Прежние цели совместимости сохранены; проверяется не каждая промежуточная версия. Нужна Java 17 или более новая по требованиям сервера. |
| BungeeCord | Компиляция с 1.21-R0.4; полного теста настоящего прокси нет. Минимум Java 17. |
| Velocity / Cardboard / Fabric | Плагин прокси Velocity не поддерживается; остальные реализации требуют отдельной проверки. Для Fabric нужен слой совместимости Bukkit, например Cardboard. |

Тест использует подмены Player/CraftPlayer и не имитирует подключённого клиента, все действия в меню, настоящее согласование MySQL TLS или все сочетания интеграций. Vault, PlaceholderAPI, MVdWPlaceholderAPI и NametagEdit подключаются при наличии совместимого провайдера. Отрисовка у клиента и настоящий сервер Cardboard требуют отдельных ручных проверок.

Версия исходного кода: 5.6.20. Сборка: Gradle 8.14.6 / JDK 21; целевой байткод приложения: Java 17. API компиляции остаётся Spigot 1.21.11, а `api-version: 1.13` задаёт базовый API и не доказывает работу каждой версии.

При отказе настроенного MySQL сервер/прокси останавливается без загрузки старых локальных прав. Каждый запуск с отказом проверяет сохранность локальных файлов прав.

```sh
python tools/verify_paper.py --paper-version 26.3 --plugin build/libs/UltraPermissions.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime-26.3 --report-dir build/reports/runtime --accept-eula
```

Для Folia укажите `--platform Folia --server-version 26.3` и новую рабочую папку. Флаг EULA относится к одноразовому серверу. Тестовый контейнер работает без внешней сети и опубликованных портов. Доступ к сети нужен проверенному загрузчику при подготовке зависимостей.

На Folia два локальных клиента входят в разные регионы. CI проверяет открытие и навигацию в оригинальном GUI, обработку ввода в потоке игрока, уникальные ID параллельно выданных прав и их сохранение после перезапуска.

Выпуски включают `runtime-verification.json` для 26.3 и `compatibility-verification.json` для всей матрицы.
