# Совместимость с Minecraft до 26.2

Стабильный выпуск 5.6.9 поддерживает **Paper для Minecraft Java Edition 26.2 на Java 25** в пределах описанных ниже проверок. Предыдущие версии Bukkit/Spigot/Paper остаются целевыми для совместимости; они протестированы не все. Поле `api-version: 1.13` задаёт базовый API, а не доказывает работоспособность на каждой промежуточной версии сервера.

| Сервер | Java | Проверка в этом выпуске |
| --- | --- | --- |
| Paper 26.2, сборка 135 | 25 | Успешный запуск изолированного сервера и 12 проверок во время выполнения. |
| Paper 26.1.x | 25 | Поддержка формата версии; отдельный запуск не проверялся. |
| Bukkit/Spigot/Paper 1.13–1.21.11 | Минимум 17; также нужно выполнить требования сервера к Java | Целевая совместимость со старыми версиями; компиляция со Spigot API 1.21.11. Полной матрицы запусков нет. |
| BungeeCord | Минимум 17 | Компиляция с API 1.21-R0.4; полная интеграция прокси и сети не проверена. |

Требования Paper к Java приведены в [официальной документации](https://docs.papermc.io/paper/getting-started/#requirements). Матрица относится к серверным плагинам Java Edition. Другие реализации сервера требуют отдельной проверки.

## Что проверяется при запуске

GitHub Actions запускает точный JAR выпуска на **Paper 26.2, сборка 135 / Java 25** в отдельном контейнере Docker. Проверяются инициализация плагина, определение материалов и версии, настоящие метаданные предметов Bukkit и сериализация предметов GUI, создание инвентаря, членство в группах и хранение унаследованных прав, вызов консольной команды, разрешённые и запрещённые права с настоящим хранилищем и подмена поля прав в фактическом классе CraftPlayer.

Поиск прав использует тестовый прокси Player; подмена поля — неинициализированный тестовый CraftPlayer. Эти проверки не моделируют подключённый клиент Minecraft, все действия GUI, внешние интеграции, настоящую сеть прокси или согласование TLS с MySQL. `RuntimeProbe.jar` — вспомогательный тестовый плагин, который не входит в устанавливаемый плагин и файлы выпуска.

JAR Paper и образ контейнера Java закреплены по SHA-256. Сеть доступна только на этапе подготовки зависимостей Paper; плагин работает с `--network none`, без опубликованных портов и с новым каталогом данных. Выпуск ожидает успешного прохождения этой проверки и сборок на обеих ОС.

Воспроизведение после `gradlew build`, если установлены Python 3 и Docker:

```sh
python tools/verify_paper.py --plugin build/libs/UltraPermissions-5.6.9.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime --report-dir build/reports/runtime --accept-eula
```

Каждый раз используйте новый рабочий каталог. `--accept-eula` явно принимает [Minecraft EULA](https://aka.ms/MinecraftEULA) для временного тестового сервера. Отчёты содержат хеш проверенного плагина и версии окружения. Перед обновлением создайте резервную копию данных сервера.
