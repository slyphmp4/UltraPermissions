# UltraPermissions 5.6.19 — Minecraft 26.3 compatibility

One **UltraPermissions.jar** covers the existing compatibility targets and Minecraft 26.3. The original TechsCode GUI, the previously approved five-row update settings, commands, EN/RU/UK translations and stored data formats are retained.

## Compatibility and verification

- Fixed head-texture application on Paper releases whose internal skull metadata class is not public, using the public Bukkit API. Fresh heads can receive their texture without pre-existing metadata; stable profile IDs and the bounded cache are retained.
- The same JAR runs the isolated Paper runtime suite on **1.20.1, 1.20.6, 1.21.11, 26.1.2, 26.2 and 26.3**, with pinned server checksums and Java 17/21/25 containers.
- Each target checks grants, denials, inheritance, rank paths, head profiles, update-menu metadata and languages, persistence across restart, native update staging, and startup protection when configured MySQL is unavailable.
- Paper 26.2 and 26.3 run the synthetic 512-profile / 400,000-permission-check load suite. Linux/Windows builds, API contracts, security checks, translations and byte-for-byte reproducibility remain release gates.
- Release reports verify that all six targets tested the exact published JAR. Parser regressions cover the 26.3 version and build suffix formats.
- Java 17 bytecode, the Spigot 1.21.11 compile API and the existing plugin API baseline remain unchanged.

These are server checks using synthetic Player/CraftPlayer fixtures. Connected-client rendering, all GUI interactions, actual Cardboard/Fabric behavior, earlier unlisted server versions and optional integrations are not exhaustively tested. See the [compatibility matrix](../COMPATIBILITY.md).

## Install

Stop the server, back up the current JAR, `plugins/UltraPermissions/` and any database, replace the plugin with **UltraPermissions.jar**, and restart. No permission-data migration is required. Use the Java version required by your server; Minecraft 26.x requires Java 25.
