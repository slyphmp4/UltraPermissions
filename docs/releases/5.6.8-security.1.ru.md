## UltraPermissions 5.6.8-security.1

Первый публичный предварительный выпуск сборки сообщества с исправлениями безопасности.

- Полный Gradle/IntelliJ IDEA проект, локальные закреплённые зависимости и обложка.
- Исправлены 3 проблемы HIGH и 5 MEDIUM: сообщения с подписью, локальное хранение секретов MySQL, связывание параметров SQL, ограниченная синхронизация/работа с пулом, отзыв доступа к GUI, безопасный кодек предметов и TLS без небезопасного резервного режима.
- Административные команды централизованно требуют superadmin; ограниченное делегирование выдачи групп сохранено.
- GitHub Actions: чистая сборка и проверки компонентов/безопасности на Ubuntu и Windows с JDK 21.

**Миграция:** обновите все узлы, настройте security.properties и MySQL локально на каждом из них. Старый протокол сообщений не поддерживается. Автоматическое скачивание/установка JAR и удалённые restart/update отключены. Используйте проверенные файлы и ручную установку.

Устанавливайте основной JAR; JAR исходников и Gradle ZIP предназначены для разработки. SHA256SUMS.txt содержит контрольные суммы файлов релиза. Полная инструкция настройки и команды — в README/docs репозитория.

Проверки CI офлайн; полное окружение Minecraft и реальная TLS-сессия не проверялись. Сначала используйте тестовый сервер/копию данных. Вредоносный имплант не установлен: этот выпуск исправляет уязвимости и не заявляет удаление вирусов.

Документация доступна на английском, украинском и русском. Gradle ZIP содержит обновлённую документацию.
