# UltraPermissions 5.6.13 — независимые уведомления и автоматические обновления

Небольшое развитие [5.6.12](https://github.com/slyphmp4/UltraPermissions/releases/tag/v5.6.12). Оригинальный GUI TechsCode, команды, узлы прав и форматы данных сохранены.

## Новые настройки обновления

- В разделе **«Настройки → Персонализация»** теперь четыре равномерно расположенные кнопки: префикс, уведомления об обновлениях, внутриигровое обновление и интервал обновления GUI. Сохранены оригинальные предметы, золотисто-жёлтая анимация названий, подсказки и навигация TechsCode.
- **Уведомления в чате** независимо включают или выключают сообщения для суперадминистраторов. При выключенном автоскачивании новая стабильная версия из GitHub Releases всё равно отображается в чате со ссылкой, но JAR не скачивается.
- **Внутриигровое средство обновления** независимо управляет автоматическим скачиванием **опубликованных стабильных релизов** из [основного репозитория](https://github.com/slyphmp4/UltraPermissions/releases). При выключенных чат-уведомлениях проверенный JAR всё равно скачивается и готовится к установке, без сообщений игроку.
- Если выключены оба параметра, проверок и сообщений нет; если включены оба — работают обе функции. Все новые подписи, состояния и сообщения переведены на русский и украинский: по **835 зарегистрированных ключей**.
- Настройки сохраняются после перезапуска. При миграции из старого формата **оба** параметра первоначально наследуют прежний `updaterEnabled` — ранее отключённая функция не включится неожиданно.

## Безопасность обновления

- Сохранены проверка SHA-256 файла из GitHub Releases, резервирование старого JAR, стандартная папка обновлений Bukkit, защита от перезаписи и отмена незавершённых скачиваний.
- **Горячей загрузки и принудительного рестарта нет.** Изменение применяется **только после следующего ручного перезапуска сервера**.
- SHA-256 из метаданных GitHub — проверка целостности, но не независимая подпись разработчика.

## Результаты проверок и ограничения

- **PASS (GitHub CI):** сборки Ubuntu/Windows на JDK 21, побайтово идентичные JAR, **459 проверок безопасности и регрессий в 20 группах**, полные русская и украинская локализации.
- **PASS (GitHub CI):** Paper 26.2 / Java 25, два полных запуска, сохранность данных и 29 серверных проверок; синтетическая нагрузка 512 профилей и 400 000 проверок прав (это не 512 подключённых игроков).
- **НЕ ПРОВЕРЕНО:** ручное нажатие четырёх кнопок в клиенте Minecraft, реальное автоматическое скачивание/установка 5.6.12 → 5.6.13, старые версии Spigot/Paper, Cardboard, Bungee/Waterfall, сбои MySQL и большой онлайн настоящих игроков. CI не гарантирует совместимость с этими сценариями.

## Установка и откат

1. Выключите сервер и создайте резервную копию прежнего JAR, данных UltraPermissions и базы данных, если используется.
2. Установите **UltraPermissions-5.6.13.jar** из выпуска, удалив дубликаты старых JAR из `plugins/`. Не устанавливайте JAR с исходниками или ZIP проекта.
3. Запустите сервер и проверьте оба переключателя в разделе «Настройки → Персонализация».
4. Если в 5.6.12 автоскачивание было включено, после публикации проверенного JAR версия 5.6.13 должна подготовиться автоматически, но для применения нужен ручной рестарт. Реальный переход ещё не проверялся.
5. Для отката верните **и предыдущий JAR, и соответствующую резервную копию данных** на выключенном сервере.
