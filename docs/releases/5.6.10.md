# UltraPermissions 5.6.10 — Russian and Ukrainian localization

This release completes the built-in Russian localization and adds Ukrainian for UltraPermissions, while retaining the security and Minecraft 26.2 compatibility fixes from 5.6.9. Original UltraPermissions authorship belongs to TechsCode; community maintenance and publication are by slyphmp4.

## Localization

- **805 of 805 plugin phrase keys translated into each language:** 275 base-interface keys and 530 UltraPermissions keys. This covers command messages, help, menus, settings, permission editor, group paths, migration prompts, placeholders and notifications.
- **159 entity names per language** for the entity picker. Material selectors use Minecraft's localized item names.
- Both language packs are **bundled in the plugin JAR** and installed to the plugin's `Languages` folder on startup, without downloading a translation archive or requiring an internet connection. Bundled Russian/Ukrainian files are refreshed when updating; keep custom modifications in separate copies.
- Fixed a legacy translation-loader bug that silently ignored four keys containing underscores, including rank-timer and prefix/suffix-color placeholder descriptions.
- Preserved command/permission syntax, variable placeholders and color-format markers. The localization checker guards exact key coverage, placeholder consistency, color markers, Latin text in translated resources and packaged JAR contents.

## Verification and compatibility

Ubuntu and Windows builds on JDK 21, security/component checks, and an isolated **Paper 26.2 / Java 25** load/runtime probe are required before the release is published. This probe does not simulate a connected Minecraft client or a complete manual walkthrough of every GUI screen. See the [compatibility matrix](../COMPATIBILITY.md) and [security notes](../SECURITY-CHANGES.md).

## Download and update

Install **UltraPermissions-5.6.10.jar** from this release (not the sources JAR). Back up plugin data, remove duplicate plugin JARs, and restart the server. On networks, update trusted nodes together. The release also provides the complete Gradle project ZIP, source JAR, runtime verification report and SHA-256 checksums.

Commands, permissions and configuration remain documented in the [command guide](../COMMANDS.md), [permissions guide](../PERMISSIONS.md) and [configuration guide](../CONFIGURATION.md).
