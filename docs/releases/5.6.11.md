# UltraPermissions 5.6.11 — GitHub Releases updates and localization fixes

This community maintenance release makes the in-game updater useful again and fixes the remaining known RU/UK interface gaps. UltraPermissions was originally developed by TechsCode; this fork is maintained and published by slyphmp4.

## In-game update notifications

- The IngameUpdater setting now checks the **published stable release** of **slyphmp4/UltraPermissions** through the official GitHub Releases API, not the former TechsCode update service.
- Checks happen asynchronously, with a 30-minute successful-result cache and conservative timeouts. Temporary GitHub failures do not block the server or report a false update.
- Internal UltraPermissions superadmins are offered the familiar update GUI when joining if a newer stable version exists and the setting is enabled. Other players are not interrupted.
- The Update button shows the **official GitHub Releases link** and manual installation/restart instructions. **Automatic JAR replacement, paid-service authentication and remote restarts remain disabled** for security.

## Russian and Ukrainian

- Fixed four IngameUpdater GUI strings that stayed English because their Phrase fields were not static and never registered with the translation manager.
- Translated remaining known hard-coded time-picker labels, zero-duration and tick text, and permanent-status values returned by timer placeholders and PlaceholderAPI.
- Both bundled locales now cover **813/813 registered phrases each**: 281 Base phrases and 532 UltraPermissions phrases. The existing 159 localized entity labels per language remain included.
- CI now rejects non-static Phrase declarations, in addition to checking keys, markers, placeholders, stray Latin text, and bundled translation resources.

## Verification and compatibility

- The release workflow requires Linux and Windows builds, component/security checks, localization validation, and an isolated **Paper 26.2 / Java 25** runtime probe before publishing binaries.
- The runtime probe is not a complete GUI walkthrough and does not certify hybrid **Cardboard (Paper + Fabric)** environments. Please report remaining dynamic English text with screenshots and reproduction steps.
- Original TechsCode GUI layout, colors, command names, permission nodes, and configuration formats are retained.

## Installation

1. Back up the server and the UltraPermissions plugin data folder.
2. Download **UltraPermissions-5.6.11.jar** from this release. Do not install the sources JAR or the Gradle project ZIP as a plugin.
3. Stop the server, remove the old UltraPermissions JAR (avoid duplicates), put the new JAR in `plugins`, and restart.
4. Choose Russian or Ukrainian in the language settings if needed. Existing permission data and server configuration should be preserved.

See the [compatibility matrix](../COMPATIBILITY.md) and [security changes](../SECURITY-CHANGES.md).
