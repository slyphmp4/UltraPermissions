# UltraPermissions 5.6.20 · Folia 26.3

Install the same **UltraPermissions.jar** on Folia 26.3 (Java 25) or one of the existing supported Paper versions.

- Inventories, dialogs, timed permission attachments and player updates run in the region that owns the player. Global maintenance and blocking background work use their respective Folia schedulers.
- Concurrent permission creation allocates unique IDs. Storage refreshes fetch a fresh snapshot if they overlap a write.
- The release checks Folia with two connected players in different regions and runs the existing six Paper compatibility targets against the same JAR.

See the [compatibility matrix](../COMPATIBILITY.md) for the pinned builds and test coverage.
