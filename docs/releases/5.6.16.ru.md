# UltraPermissions 5.6.16 — стабильные головы игроков

Обновление устраняет причину быстрого мерцания текстур голов игроков в редакторе TechsCode. Исходное расположение элементов GUI, слоты, иконки, анимации текста, команды, переводы и форматы данных не меняются.

## Исправления

- Профиль головы теперь получает постоянный UUID на основе URL текстуры вместо нового случайного UUID при каждой перерисовке. При изменении скина создаётся новый профиль без изменения сохранённых данных пользователя.
- Ограниченный кеш повторно использует до 1024 профилей голов. Современный Bukkit API применяется для установки текстур; резервный механизм authlib сохранён для старых реализаций.
- Слоты инвентаря перезаписываются только при изменении предмета. Если кадр не изменился, принудительное обновление инвентаря не планируется. Анимации текста и исходное переключение голов на кнопке Users главного экрана сохранены.

## Проверки и ограничения

Проверки выпуска включают сборки Linux/Windows, компоненты и безопасность, переводы, воспроизводимость, реальный сервер Paper 26.2 и синтетическую нагрузку. Добавлены тесты стабильности UUID, повторного использования и вытеснения кеша, а также метаданных голов на Paper для неизменённых и новых текстур. Отображение у подключённого клиента и на Cardboard/Fabric требует отдельной визуальной проверки — автоматические тесты не эмулируют отрисовку текстур клиентом.

## Установка / откат

Остановите сервер, сохраните прежний JAR, `plugins/UltraPermissions/` и БД, установите **UltraPermissions.jar** и перезапустите сервер. Перенос настроек и данных прав не требуется. Автообновлятор подготавливает проверенный выпуск к следующему ручному перезапуску. См. [настройку](../CONFIGURATION.ru.md) и [совместимость](../COMPATIBILITY.ru.md).
