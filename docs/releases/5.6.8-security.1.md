## UltraPermissions 5.6.8-security.1

First public pre-release of the community security build.

- Complete Gradle/IntelliJ IDEA project, pinned local dependencies and cover artwork.
- Addresses 3 HIGH and 5 MEDIUM findings: signed messaging, local-only MySQL secrets, SQL parameter binding, bounded synchronization/pool handling, GUI-access revocation, a safe item codec and fail-closed TLS.
- Administrative commands centrally require superadmin; limited group-assignment delegation remains available.
- GitHub Actions: clean builds and component/security checks on Ubuntu and Windows with JDK 21.

**Migration:** update every node and configure security.properties and MySQL locally on each one. The old messaging protocol is unsupported. Automatic JAR downloads/installation and remote restart/update are disabled. Use verified files and manual installation.

Install the main JAR; the sources JAR and Gradle ZIP are for development. SHA256SUMS.txt contains checksums for the release assets. Full setup instructions and commands are in the repository's README/docs.

CI checks are offline; the full Minecraft runtime and a real TLS session were not tested. Start with a test server/data copy. No malicious implant was established: this release fixes vulnerabilities and does not claim virus removal.

Documentation is available in English, Ukrainian and Russian. The Gradle project ZIP includes the updated documentation.
