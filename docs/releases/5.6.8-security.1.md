## UltraPermissions 5.6.8-security.1

Первый public pre-release community security-сборки.

- Полный Gradle/IntelliJ IDEA проект, локальные закреплённые зависимости и обложка.
- Исправлены 3 HIGH и 5 MEDIUM: signed messaging, local-only MySQL secrets, SQL binding, ограниченный sync/pool, отзыв GUI-доступа, безопасный item codec и fail-closed TLS.
- Административные команды централизованно требуют superadmin; сохранена ограниченная выдача групп.
- GitHub Actions: чистая сборка и проверки компонентов/безопасности на Ubuntu и Windows, JDK 21.

**Миграция:** обновите все узлы, настройте security.properties и MySQL локально на каждом узле. Старый messaging protocol не поддерживается. Автоматическое скачивание/установка JAR и удалённый restart/update отключены. Используйте проверенные файлы и ручную установку.

Устанавливайте основной JAR; sources JAR и Gradle ZIP — для разработки. SHA256SUMS.txt содержит контрольные суммы assets. Полная инструкция и команды — в README/docs репозитория.

Проверки CI офлайн, полный Minecraft runtime и реальная TLS-сессия не проверялись; сначала используйте тестовый сервер/копию данных. Вредоносный имплант не установлен: этот выпуск исправляет уязвимости, а не заявляет удаление вирусов.
