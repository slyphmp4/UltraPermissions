# UltraPermissions 5.6.16 — стабільні голови гравців

Оновлення усуває причину швидкого мерехтіння текстур голів гравців у редакторі TechsCode. Початкове розташування елементів GUI, слоти, піктограми, анімації тексту, команди, переклади й формати даних не змінюються.

## Виправлення

- Профіль голови тепер отримує сталий UUID на основі URL текстури замість нового випадкового UUID під час кожного перемальовування. Коли скін змінюється, створюється новий профіль без зміни збережених даних користувача.
- Обмежений кеш повторно використовує до 1024 профілів голів. Сучасний Bukkit API застосовується для встановлення текстур; резервний механізм authlib збережено для старих реалізацій.
- Слоти інвентарю перезаписуються лише тоді, коли предмет змінюється. Якщо кадр не змінився, примусове оновлення інвентарю не планується. Анімації тексту й початкове перемикання голів на кнопці Users головного екрана збережено.

## Перевірки й обмеження

Перевірки випуску охоплюють збирання Linux/Windows, компоненти й безпеку, переклади, відтворюваність, справжній сервер Paper 26.2 і синтетичне навантаження. Додано тести сталості UUID, повторного використання й витіснення кешу, а також метаданих голів на Paper для незмінних і нових текстур. Відображення у підключеного клієнта й на Cardboard/Fabric потребує окремої візуальної перевірки — автоматичні тести не імітують клієнтське відображення текстур.

## Встановлення / відкат

Зупиніть сервер, збережіть попередній JAR, `plugins/UltraPermissions/` і БД, установіть **UltraPermissions.jar** та перезапустіть сервер. Перенесення налаштувань і даних прав не потрібне. Автооновлювач готує перевірений випуск до наступного ручного перезапуску. Див. [налаштування](../CONFIGURATION.uk.md) і [сумісність](../COMPATIBILITY.uk.md).
