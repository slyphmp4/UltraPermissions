# UltraPermissions 5.6.11 — обновления через GitHub и исправления перевода

В этой версии снова заработала проверка обновлений из игры и исправлены оставшиеся известные пробелы русского и украинского интерфейса. Первоначальный разработчик UltraPermissions — TechsCode; сопровождением форка и публикацией занимается slyphmp4.

## Уведомления об обновлениях

- Настройка **IngameUpdater** теперь проверяет **последний опубликованный стабильный релиз** в **slyphmp4/UltraPermissions** через официальный GitHub API. Старый сервис обновлений TechsCode больше не используется.
- Запросы выполняются в фоне, успешный результат кэшируется на 30 минут. При недоступности GitHub сервер не зависает и не показывает ложные уведомления.
- При входе на сервер **внутренний супер-администратор** UltraPermissions увидит привычное окно обновления, если доступна новая стабильная версия и настройка включена. Обычные игроки уведомлений не получают.
- Кнопка обновления показывает **ссылку на GitHub Releases** и инструкцию по ручной установке. **Автоматическая замена JAR, авторизация через платный сервис и удалённые перезапуски отключены** ради безопасности.

## Русский и украинский интерфейс

- Исправлены четыре строки окна IngameUpdater, которые оставались английскими: поля Phrase не были статическими, поэтому менеджер переводов их не регистрировал.
- Переведены найденные жёстко заданные надписи выбора длительности, нулевое время, обозначения тиков и статус «Навсегда» в таймерах и PlaceholderAPI.
- В каждом встроенном переводе теперь **813 из 813 зарегистрированных строк**: 281 базовая и 532 строки UltraPermissions. Сохранились **159 переводов названий существ** на каждый язык.
- CI дополнительно запрещает нестатические поля Phrase и проверяет ключи, цветовые маркеры, подстановки, латиницу и содержимое языковых пакетов в JAR.

## Проверка и совместимость

- Публикация требует успешных сборок на Linux и Windows, проверок безопасности, полноты переводов и изолированного запуска **Paper 26.2 / Java 25**.
- Автоматический тест не заменяет ручную проверку всех окон и не гарантирует работу каждой конфигурации **Cardboard (Paper + Fabric)**. Если заметите английский текст, приложите скриншот и шаги воспроизведения.
- Стиль исходного GUI TechsCode, цвета, названия команд, узлы прав и формат конфигурации сохранены.

## Установка

1. Сделайте резервную копию сервера и папки данных UltraPermissions.
2. Скачайте **UltraPermissions-5.6.11.jar** из этого релиза. JAR с исходниками и ZIP проекта для установки на сервер не подходят.
3. Выключите сервер, уберите старый JAR UltraPermissions (без дубликатов), установите новый файл в `plugins` и запустите сервер.
4. При необходимости выберите русский или украинский язык в настройках. Данные прав и конфигурация должны сохраниться.
