# UltraPermissions 5.6.18 — larger update settings window

Update Settings now has **five rows (45 slots)** instead of three. The existing notification, automatic-download and status items remain at slots **12, 14 and 16**. The original Back sign moves from slot 23 to **slot 41**, the center of the bottom row. Slot numbers are one-based.

The change uses the existing Bukkit GUI implementation. Item materials, names, lore, colors, animations and actions are preserved. Updater behavior, stored preferences, permission data and dependencies are unchanged. The production file remains **UltraPermissions.jar**.

Existing offline and real-Paper layout checks now verify 45 slots, the unchanged content positions and the relocated Back action. Linux/Windows builds, reproducibility, localization, persistence and load checks remain release gates. Connected-client and Cardboard/Fabric visual verification remains manual.

See [configuration](../CONFIGURATION.md) and [compatibility](../COMPATIBILITY.md).
