# UltraPermissions 5.6.20 · Folia 26.3

Установите **UltraPermissions.jar** на Folia 26.3 с Java 25 или на одну из поддерживаемых версий Paper.

- Инвентари, диалоги, временные права от других плагинов и обновления игроков выполняются в потоке региона игрока. Общие и фоновые задачи используют соответствующие планировщики Folia.
- Параллельная выдача прав получает уникальные ID. Если чтение из хранилища пересеклось с записью, плагин перечитывает данные перед применением.
- CI проверяет Folia с двумя подключёнными игроками в разных регионах и прогоняет тот же JAR на шести версиях Paper.

Закреплённые сборки и покрытие тестами перечислены в [матрице совместимости](../COMPATIBILITY.ru.md).
