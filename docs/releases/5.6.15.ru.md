# UltraPermissions 5.6.15 — целостность прав и обновление компонентов

Исправлены четыре ошибки, найденные аудитом 5.6.14, обновлены сборка и библиотеки. GUI TechsCode, команды, узлы прав и существующие форматы данных сохранены.

## Изменения для администратора

- `/promote` и `/demote` определяют текущую группу заново при каждом вызове. Группа предыдущего игрока не применяется к другому пользователю или пути рангов.
- Префиксы, суффиксы и другие значения сохраняют изменения только регистра букв, в том числе при полной синхронизации кеша.
- Отклонённые и незавершённые входы не удерживают сессии игроков и не создают записи аккаунтов. Для существующих пользователей сохранены ранние проверки прав; новый аккаунт регистрируется после успешного входа.
- **Если настроенное MySQL-хранилище не открывается, сервер/прокси останавливается с понятным сообщением в консоли. Перехода на старые локальные права нет.** Повреждённое начальное хранилище также отклоняется. Исправьте доступ к БД, TLS/драйвер или повреждённые данные и перезапустите сервер; не удаляйте настройки ради обхода ошибки.
- Выборочная синхронизация локального ключа читает только нужную запись. MySQL читает строки потоком и отклоняет результат с суммарным размером закодированных значений более 64 МиБ, сохраняя существующие данные при отказе.
- Удалены персональные метаданные покупателя, устаревшие описания поставщиков сервисов и лишний вывод путей рангов в журнал.

## Библиотеки и сборка

Gradle 8.14.6 закрывает опубликованные уязвимости каналов daemon. Обновлены Gson 2.15.0, HikariCP 7.1.0, NBT API 2.16.1, Commons Codec/IO/Lang/Logging, SLF4J и bStats; источники и SHA-256 закреплены. Обычная сборка остаётся офлайн. Неизменённый Apache HTTP 4.x и внутренние подмножества Kyori/JetBrains с неизвестными версиями по-прежнему явно описаны; неподтверждённого перехода на другую платформу нет.

## Проверки и ограничения

Релиз требует успешных сборок Windows/Linux, отрицательных регрессий безопасности, 7085 контрактов API, побайтной воспроизводимости архивов, проверки переводов, реального теста Paper 26.2 / Java 25 с сохранением данных и применением подготовленного обновления, а также запуска с недоступным настроенным MySQL. Нагрузочный тест использует синтетические профили, а не подключённых клиентов. Точные результаты и хеш JAR находятся в приложенном к релизу отчёте.

Запись по-прежнему подтверждается после сохранения и может задерживаться на медленном хранилище. Этот выпуск ограничивает чтение и исправляет корректность, сохраняя контракт записи и форматы данных. Настоящий MySQL TLS handshake, все сочетания интеграций, BungeeCord и матрица старых серверов не проверены исчерпывающе.

## Установка / откат

Остановите сервер, сохраните прежний JAR, `plugins/UltraPermissions/` и БД, установите **UltraPermissions.jar** и перезапустите сервер. Существующий автообновлятор подготавливает файл к следующему ручному перезапуску. Для отката остановите сервер и восстановите соответствующие копии JAR и данных. См. [настройку](../CONFIGURATION.ru.md), [совместимость](../COMPATIBILITY.ru.md) и [происхождение компонентов](../../THIRD-PARTY.ru.md).
