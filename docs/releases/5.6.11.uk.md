# UltraPermissions 5.6.11 — оновлення через GitHub та виправлення перекладу

У цьому випуску відновлено перевірку оновлень у грі й усунено решту відомих прогалин російського та українського інтерфейсу. Початковий розробник UltraPermissions — TechsCode; форк підтримує та публікує slyphmp4.

## Сповіщення про оновлення

- Налаштування **IngameUpdater** тепер перевіряє **останній опублікований стабільний реліз** у **slyphmp4/UltraPermissions** через офіційний GitHub API. Старий сервіс оновлень TechsCode більше не використовується.
- Запити виконуються у фоновому режимі, успішний результат кешується на 30 хвилин. Якщо GitHub недоступний, сервер не зависає та не показує хибних оновлень.
- Під час входу **внутрішній суперадміністратор** UltraPermissions бачить звичне вікно оновлення, якщо є нова стабільна версія та налаштування ввімкнене. Інших гравців сповіщення не турбують.
- Кнопка оновлення показує **посилання на GitHub Releases** та інструкцію з ручного встановлення. **Автоматичну заміну JAR, авторизацію через платний сервіс і віддалені перезапуски вимкнено** задля безпеки.

## Російський та український інтерфейс

- Виправлено чотири рядки IngameUpdater, які залишалися англійськими: поля Phrase не були статичними, тому менеджер перекладів їх не реєстрував.
- Перекладено знайдені жорстко задані написи вибору тривалості, нульовий час, позначення тіків і статус «Назавжди» в таймерах та PlaceholderAPI.
- У кожному вбудованому перекладі тепер **813 із 813 зареєстрованих рядків**: 281 базовий і 532 рядки UltraPermissions. Збережено **159 перекладів назв сутностей** кожною мовою.
- CI додатково забороняє нестатичні поля Phrase та перевіряє ключі, кольорові маркери, підстановки, латинські слова й мовні ресурси в JAR.

## Перевірка та сумісність

- Публікація потребує успішних збірок на Linux і Windows, перевірок безпеки й локалізації та ізольованого запуску **Paper 26.2 / Java 25**.
- Автоматичний тест не замінює ручної перевірки кожного вікна й не гарантує сумісність з усіма конфігураціями **Cardboard (Paper + Fabric)**. Якщо знайдете англійський текст, додайте знімок екрана та кроки відтворення.
- Оригінальний стиль GUI TechsCode, кольори, назви команд, вузли прав та формат конфігурації збережено.

## Встановлення

1. Створіть резервну копію сервера та папки даних UltraPermissions.
2. Завантажте **UltraPermissions-5.6.11.jar** із цього випуску. JAR вихідного коду та ZIP проєкту не призначені для встановлення на сервер.
3. Зупиніть сервер, приберіть старий JAR UltraPermissions (без дублікатів), покладіть новий файл до `plugins` та перезапустіть сервер.
4. За потреби виберіть російську або українську мову в налаштуваннях. Дані прав і конфігурація мають зберегтися.
