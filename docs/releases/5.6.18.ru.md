# UltraPermissions 5.6.18 — расширенное окно настроек обновлений

В «Настройках обновлений» теперь **пять рядов (45 слотов)** вместо трёх. Предметы уведомлений, автоскачивания и статуса остаются в слотах **12, 14 и 16**. Исходная табличка «Назад» переносится из слота 23 в **слот 41**, по центру нижнего ряда. Нумерация слотов начинается с единицы.

Используется существующая реализация GUI на Bukkit. Сохранены материалы, названия, описания, цвета, анимации и действия предметов. Поведение обновлятора, сохранённые настройки, данные прав и зависимости не меняются. Основной файл по-прежнему называется **UltraPermissions.jar**.

Существующие проверки без сети и на реальном Paper теперь проверяют 45 слотов, прежние позиции основных предметов и действие перенесённой кнопки «Назад». Сборки Linux/Windows, воспроизводимость, переводы, сохранение данных и нагрузочные проверки остаются условиями выпуска. Визуальная проверка с подключённым клиентом и на Cardboard/Fabric остаётся ручной.

См. [настройку](../CONFIGURATION.ru.md) и [совместимость](../COMPATIBILITY.ru.md).
