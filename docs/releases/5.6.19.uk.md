# UltraPermissions 5.6.19 — сумісність із Minecraft 26.3

Один **UltraPermissions.jar** розраховано на попередні цілі сумісності та Minecraft 26.3. Збережено оригінальний GUI TechsCode, раніше погоджені п’ять рядів налаштувань оновлень, команди, переклади EN/RU/UK і формати даних.

## Сумісність і перевірки

- Виправлено застосування текстур голів на версіях Paper з непублічним внутрішнім класом метаданих: використовується публічний Bukkit API. Текстура застосовується й до нових голів без попередніх метаданих; сталі UUID та обмежений кеш збережено.
- Один і той самий JAR проходить ізольовані серверні тести Paper **1.20.1, 1.20.6, 1.21.11, 26.1.2, 26.2 та 26.3**, із закріпленими контрольними сумами серверів і контейнерами Java 17/21/25.
- Для кожної версії перевіряються надання й заборона прав, успадкування, шляхи рангів, профілі голів, метадані меню оновлень і мови, збереження після перезапуску, стандартне встановлення відкладеного оновлення та захист запуску за недоступного налаштованого MySQL.
- Paper 26.2 і 26.3 проходять синтетичний навантажувальний тест: 512 профілів і 400 000 перевірок прав. Збірки Linux/Windows, контракти API, безпека, переклади й побайтова відтворюваність залишаються обов’язковими перевірками випуску.
- Звіти випуску підтверджують, що всі шість версій перевіряли саме опублікований JAR. Додано перевірки розбору номера 26.3 і суфіксів збірок.
- Збережено байткод Java 17, API компіляції Spigot 1.21.11 і попередній базовий API плагіна.

Серверні тести використовують підміни Player/CraftPlayer. Відображення у підключеного клієнта, всі дії в GUI, справжній Cardboard/Fabric, попередні версії поза списком і поєднання інтеграцій не перевіряються вичерпно. Див. [матрицю сумісності](../COMPATIBILITY.uk.md).

## Встановлення

Зупиніть сервер, збережіть поточний JAR, `plugins/UltraPermissions/` і БД, замініть плагін файлом **UltraPermissions.jar** та перезапустіть сервер. Перенесення даних прав не потрібне. Використовуйте Java, необхідну вашому серверу; для Minecraft 26.x потрібна Java 25.
