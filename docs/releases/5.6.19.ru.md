# UltraPermissions 5.6.19 — совместимость с Minecraft 26.3

Один **UltraPermissions.jar** рассчитан на прежние цели совместимости и Minecraft 26.3. Сохранены оригинальный GUI TechsCode, ранее согласованные пять рядов настроек обновлений, команды, переводы EN/RU/UK и форматы данных.

## Совместимость и проверки

- Исправлено применение текстур голов на версиях Paper с непубличным внутренним классом метаданных: используется публичный Bukkit API. Текстура применяется и к новым головам без прежних метаданных; постоянные UUID и ограниченный кеш сохранены.
- Один и тот же JAR проходит изолированные серверные тесты Paper **1.20.1, 1.20.6, 1.21.11, 26.1.2, 26.2 и 26.3**, с закреплёнными контрольными суммами серверов и контейнерами Java 17/21/25.
- Для каждой версии проверяются выдача и запрет прав, наследование, пути рангов, профили голов, метаданные меню обновлений и языки, сохранение после перезапуска, стандартная установка отложенного обновления и защита запуска при недоступном настроенном MySQL.
- Paper 26.2 и 26.3 проходят синтетический нагрузочный тест: 512 профилей и 400 000 проверок прав. Сборки Linux/Windows, контракты API, безопасность, переводы и побайтовая воспроизводимость остаются обязательными проверками выпуска.
- Отчёты выпуска подтверждают, что все шесть версий проверяли именно публикуемый JAR. Добавлены проверки разбора номера 26.3 и суффиксов сборок.
- Сохранены байткод Java 17, API компиляции Spigot 1.21.11 и прежний базовый API плагина.

Серверные тесты используют подмены Player/CraftPlayer. Отрисовка у подключённого клиента, все действия в GUI, настоящий Cardboard/Fabric, прежние версии вне списка и сочетания интеграций не проверяются исчерпывающе. См. [матрицу совместимости](../COMPATIBILITY.ru.md).

## Установка

Остановите сервер, сохраните текущий JAR, `plugins/UltraPermissions/` и БД, замените плагин файлом **UltraPermissions.jar** и перезапустите сервер. Перенос данных прав не требуется. Используйте Java, необходимую вашему серверу; для Minecraft 26.x нужна Java 25.
