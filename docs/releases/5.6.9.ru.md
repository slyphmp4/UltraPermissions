# UltraPermissions 5.6.9 — стабильный выпуск

Первый стабильный выпуск этого репозитория, который поддерживает сообщество. Сохранено указание TechsCode как первоначального автора UltraPermissions; сопровождение и публикацию выполняет slyphmp4.

## Версии Minecraft

**Совместимость охватывает Minecraft Java Edition до 26.2. Paper 26.2, сборка 135 / Java 25 проходит проверку во время выполнения.** Предыдущие версии серверов и статус их проверки приведены в [матрице совместимости](../COMPATIBILITY.ru.md).

- Устранён сбой запуска маппера материалов с новыми номерами версий Minecraft на основе года.
- Исправлен разбор версий для строк Paper вида `26.2.build.135-stable`; добавлены регрессионные проверки старого и нового форматов.
- Добавлена изолированная проверка Paper 26.2 с закреплёнными зависимостями. Она проверяет инициализацию, метаданные и кодеки предметов, инвентари, хранилище, консольный вызов, поиск прав и подмену поля CraftPlayer. Подключённый клиент Minecraft не моделируется.
- Публикация выпуска требует успешных сборок на Ubuntu и Windows с JDK 21 и проверки на Paper с Java 25.

## Безопасность и проверка

Включает все исправления **3 HIGH и 5 MEDIUM** из предыдущей сборки безопасности: аутентифицированные сообщения, устранение удалённых путей передачи учётных данных/консоли/обновлений, параметризованный SQL, ограниченную синхронизацию, проверки текущего администратора и сеанса, ограниченное декодирование предметов и строгую политику TLS MySQL. Точные границы и ограничения приведены в [изменениях безопасности](../SECURITY-CHANGES.ru.md).

Проверка: **232 офлайн-проверки**, **12 проверок во время выполнения Paper**, проверки зависимостей и компонентов JAR, а также **7085 контрактов API**. Настоящая сеть прокси, игра с подключённым клиентом и согласование TLS MySQL остаются вне этих тестов. Вредоносный имплант не установлен; выпуск не заявляет об удалении вирусов или абсолютной безопасности.

## Загрузка и установка

Устанавливайте **UltraPermissions-5.6.9.jar** в `plugins`. JAR исходного кода и ZIP Gradle-проекта предназначены для разработки. `runtime-verification.json` содержит проверенные версии сервера и Java и SHA-256 плагина; `SHA256SUMS.txt` охватывает файлы выпуска.

Перед обновлением создайте резервную копию данных. Обновляйте все доверенные узлы сети вместе и настраивайте `security.properties` и MySQL локально на каждом из них. Старый протокол сообщений не поддерживается; автоматическая установка JAR и удалённые перезапуск/обновление остаются отключены. См. [настройку](../CONFIGURATION.ru.md), [команды](../COMMANDS.ru.md) и [права](../PERMISSIONS.ru.md).
