# UltraPermissions 5.6.9 — stable release

The first stable release of this community-maintained repository. Original UltraPermissions attribution to TechsCode is retained; maintenance and publication are by slyphmp4.

## Minecraft versions

**Compatibility extends through Minecraft Java Edition 26.2. Paper 26.2 build 135 / Java 25 passes the runtime gate.** Earlier server lines and their verification status are listed in the [compatibility matrix](../COMPATIBILITY.md).

- Fixed the material mapper's startup failure with Minecraft's year-based version numbers.
- Fixed reflection version parsing for Paper strings such as `26.2.build.135-stable` and added regression cases for legacy and modern formats.
- Added a pinned, isolated Paper 26.2 runtime check. It verifies initialization, item metadata/codecs, inventories, storage, console dispatch, permission lookups and CraftPlayer field injection. No connected Minecraft client is simulated.
- Release publication requires successful Ubuntu and Windows builds on JDK 21 and the Paper runtime gate on Java 25.

## Security and verification

Includes all **3 HIGH and 5 MEDIUM** fixes from the previous security build: authenticated messaging, removal of remote credential/console/update paths, prepared SQL statements, bounded synchronization, current administrator/session checks, restricted item decoding and strict MySQL TLS policy. See the [security changes](../SECURITY-CHANGES.md) for exact scope and limitations.

Validation: **232 offline assertions**, **12 Paper runtime assertions**, dependency and packaged-component checks, and **7085 API contracts**. A real proxy network, connected-client gameplay and MySQL TLS negotiation are outside these tests. No malicious implant was established; this release does not claim virus removal or absolute security.

## Downloads and installation

Install **UltraPermissions-5.6.9.jar** in `plugins`. The sources JAR and Gradle-project ZIP are for development. `runtime-verification.json` records the tested server, Java version and plugin SHA-256; `SHA256SUMS.txt` covers the downloadable artifacts.

Back up data before updating. Update all trusted network nodes together and configure `security.properties` and MySQL locally on each one. The legacy messaging protocol is unsupported; automatic JAR installation and remote restart/update remain disabled. See [configuration](../CONFIGURATION.md), [commands](../COMMANDS.md) and [permissions](../PERMISSIONS.md).
