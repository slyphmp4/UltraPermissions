# UltraPermissions 5.6.15 — цілісність прав і оновлення компонентів

Виправлено чотири помилки аудиту 5.6.14, оновлено збирання та бібліотеки. GUI TechsCode, команди, вузли прав і наявні формати даних збережено.

## Зміни для адміністратора

- `/promote` і `/demote` визначають поточну групу окремо для кожного виклику. Група попереднього гравця не застосовується до іншого користувача чи шляху рангів.
- Префікси, суфікси та інші значення зберігають зміни лише регістру літер, зокрема під час повної синхронізації кешу.
- Відхилені й незавершені входи не утримують сеанси гравців і не створюють облікових записів. Для наявних користувачів збережено ранні перевірки прав; новий запис створюється після успішного входу.
- **Якщо налаштоване сховище MySQL не відкривається, сервер/проксі зупиняється зі зрозумілим повідомленням у консолі. Переходу на старі локальні права немає.** Пошкоджене початкове сховище також відхиляється. Виправте доступ до БД, TLS/драйвер або пошкоджені дані й перезапустіть сервер; не видаляйте налаштування для обходу помилки.
- Вибіркова синхронізація локального ключа читає лише потрібний запис. MySQL читає рядки потоком і відхиляє результат із сумарним розміром закодованих значень понад 64 МіБ, зберігаючи наявні дані в разі відмови.
- Видалено персональні метадані покупця, застарілі описи постачальників сервісів і зайве журналювання шляхів рангів.

## Бібліотеки та збирання

Gradle 8.14.6 виправляє опубліковані вразливості каналів daemon. Оновлено Gson 2.15.0, HikariCP 7.1.0, NBT API 2.16.1, Commons Codec/IO/Lang/Logging, SLF4J і bStats; джерела та SHA-256 закріплено. Звичайне збирання залишається офлайн. Незмінений Apache HTTP 4.x та внутрішні підмножини Kyori/JetBrains із невідомими версіями й далі явно описано; неперевіреного переходу на іншу платформу немає.

## Перевірки й обмеження

Випуск вимагає успішного збирання Windows/Linux, негативних регресій безпеки, 7085 контрактів API, побайтової відтворюваності архівів, перевірки перекладів, реального тесту Paper 26.2 / Java 25 зі збереженням даних і застосуванням підготовленого оновлення, а також запуску з недоступним налаштованим MySQL. Навантажувальний тест використовує синтетичні профілі, а не підключених клієнтів. Точні результати та хеш JAR містяться в доданому до випуску звіті.

Запис підтверджується після збереження й може затримуватися на повільному сховищі. Цей випуск обмежує читання та виправляє коректність, зберігаючи контракт запису й формати даних. Справжній MySQL TLS handshake, усі поєднання інтеграцій, BungeeCord і матрицю старих серверів не перевірено вичерпно.

## Встановлення / відкат

Зупиніть сервер, збережіть попередній JAR, `plugins/UltraPermissions/` і БД, установіть **UltraPermissions.jar** та перезапустіть сервер. Наявний автооновлювач готує файл до наступного ручного перезапуску. Для відкату зупиніть сервер і відновіть відповідні копії JAR та даних. Див.
