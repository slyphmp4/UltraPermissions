# Сумісність із Minecraft до 26.2

Цільова платформа випуску — Paper 26.2 / Java 25. Перевірка охоплює два успішні запуски та окремий запуск із відмовою налаштованого сховища (42 твердження), перевірку метаданих голів, збереження даних і стандартну папку оновлень.

Попередні Bukkit/Spigot/Paper залишаються цілями сумісності; повної матриці запусків немає. api-version: 1.13 задає базовий API, а не підтверджує роботу кожної проміжної версії.

| Сервер | Java | Перевірка |
|---|---|---|
| Paper 26.2 build 135 | 25 | Збереження, ранги, метадані, переклади, оновлення й зупинка в разі відмови MySQL. |
| Bukkit/Spigot/Paper 1.13–1.21.11 | Мінімум 17 і вимоги самого сервера | Компіляція зі Spigot 1.21.11; повної матриці запусків немає. |
| BungeeCord | Мінімум 17 | Компіляція з 1.21-R0.4; повного тесту справжнього проксі немає. |
| Velocity / Folia / Cardboard / Fabric | Залежить від платформи | Плагін проксі Velocity не підтримується; інші реалізації потребують окремої перевірки. |

Тест використовує підміни Player/CraftPlayer й не імітує підключеного клієнта, справжнє узгодження MySQL TLS або всі поєднання інтеграцій. Vault, PlaceholderAPI, MVdWPlaceholderAPI і NametagEdit підключаються за наявності сумісного постачальника.

Версія вихідного коду: 5.6.16. Збирання: Gradle 8.14.6 / JDK 21; цільовий байткод: Java 17. Окремий навантажувальний тест використовує 512 синтетичних профілів і щонайменше 400 000 перевірок прав; це не тест підключених гравців.

У разі відмови налаштованого MySQL сервер/проксі зупиняється без завантаження старих локальних прав. Окремий запуск перевіряє збереження локальних файлів прав.

```sh
python tools/verify_paper.py --plugin build/libs/UltraPermissions.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime-5616 --report-dir build/reports/runtime --accept-eula
```

Для кожного запуску використовуйте нову робочу папку. Прапорець приймає Minecraft EULA для одноразового тестового сервера. Порти контейнера не публікуються; плагіни запускаються без мережі. Доступ до мережі має лише закріплений завантажувач Paper під час підготовки залежностей.
