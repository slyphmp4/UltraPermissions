# Сумісність із Minecraft до 26.3

Один **UltraPermissions.jar** перевіряється на кожній закріпленій збірці Paper нижче. Для кожної виконуються два успішні запуски та окремий запуск із відмовою налаштованого сховища: надання й заборона прав, успадкування, шляхи рангів, профілі голів, метадані локалізованого GUI оновлень, збереження даних і стандартна папка оновлень.

| Версія Paper | Збірка | Java |
|---|---|---|
| 1.20.1 | 196 | 17 |
| 1.20.6 | 151 | 21 |
| 1.21.11 | 132 | 21 |
| 26.1.2 | 74 | 25 |
| 26.2 | 135 | 25 |
| 26.3 | 253 | 25 |

Завантаження серверів, SHA-256 і контрольні суми контейнерів Java закріплено в [paper-targets.json](../config/paper-targets.json). CI перевіряє, що всі шість звітів стосуються одного й того самого JAR плагіна; відсутність або помилка будь-якої версії блокує випуск. На Paper 26.2 і 26.3 додатково виконується синтетичний навантажувальний тест: 512 профілів і щонайменше 400 000 перевірок прав.

| Інша платформа | Область сумісності |
|---|---|
| Попередні Bukkit/Spigot/Paper 1.13–1.21.11 | Попередні цілі сумісності збережено; перевіряється не кожна проміжна версія. Потрібна Java 17 або новіша за вимогами сервера. |
| BungeeCord | Компіляція з 1.21-R0.4; повного тесту справжнього проксі немає. Мінімум Java 17. |
| Velocity / Folia / Cardboard / Fabric | Плагін проксі Velocity не підтримується; решта реалізацій потребує окремої перевірки. Для Fabric потрібен шар сумісності Bukkit, наприклад Cardboard. |

Тест використовує підміни Player/CraftPlayer й не імітує підключеного клієнта, всі дії в меню, справжнє узгодження MySQL TLS або всі поєднання інтеграцій. Vault, PlaceholderAPI, MVdWPlaceholderAPI і NametagEdit підключаються за наявності сумісного постачальника. Відображення у клієнта та справжній сервер Cardboard потребують окремих ручних перевірок.

Версія вихідного коду: 5.6.19. Збирання: Gradle 8.14.6 / JDK 21; цільовий байткод: Java 17. API компіляції залишається Spigot 1.21.11, а `api-version: 1.13` задає базовий API й не доводить роботу кожної версії.

У разі відмови налаштованого MySQL сервер/проксі зупиняється без завантаження старих локальних прав. Кожен запуск із відмовою перевіряє збереження локальних файлів прав.

```sh
python tools/verify_paper.py --paper-version 26.3 --plugin build/libs/UltraPermissions.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime-26.3 --report-dir build/reports/runtime --accept-eula
```

Виберіть іншу закріплену версію через `--paper-version` і використовуйте нову робочу папку. Прапорець приймає Minecraft EULA для одноразового сервера. Порти контейнера не публікуються; плагіни працюють без мережі. Доступ до мережі має лише закріплений завантажувач Paper під час підготовки залежностей.

Випуски містять `runtime-verification.json` для 26.3 та `compatibility-verification.json` для всієї матриці.
