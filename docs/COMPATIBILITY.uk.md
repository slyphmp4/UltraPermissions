# Сумісність із Minecraft до 26.2

Стабільний випуск 5.6.9 підтримує **Paper для Minecraft Java Edition 26.2 на Java 25** у межах наведених нижче перевірок. Попередні версії Bukkit/Spigot/Paper залишаються цільовими для сумісності; їх не всі протестовано. Поле `api-version: 1.13` визначає базовий API, а не доводить працездатність на кожній проміжній версії сервера.

| Сервер | Java | Перевірка в цьому випуску |
| --- | --- | --- |
| Paper 26.2, збірка 135 | 25 | Успішний запуск ізольованого сервера та 12 перевірок під час виконання. |
| Paper 26.1.x | 25 | Підтримка формату версії; окремого запуску не перевіряли. |
| Bukkit/Spigot/Paper 1.13–1.21.11 | Щонайменше 17; також слід виконати вимоги сервера до Java | Цільова сумісність зі старими версіями; компіляція зі Spigot API 1.21.11. Повної матриці запусків немає. |
| BungeeCord | Щонайменше 17 | Компіляція з API 1.21-R0.4; повну інтеграцію проксі та мережі не перевірено. |

Вимоги Paper до Java наведено в [офіційній документації](https://docs.papermc.io/paper/getting-started/#requirements). Матриця стосується серверних плагінів Java Edition. Інші реалізації сервера потребують окремої перевірки.

## Що перевіряється під час запуску

GitHub Actions запускає точний JAR випуску на **Paper 26.2, збірка 135 / Java 25** в окремому контейнері Docker. Перевіряються ініціалізація плагіна, визначення матеріалів і версії, справжні метадані предметів Bukkit та серіалізація предметів GUI, створення інвентарю, членство в групах та зберігання успадкованих прав, виклик консольної команди, дозволені й заборонені права зі справжнім сховищем і підміна поля прав у фактичному класі CraftPlayer.

Пошук прав використовує тестовий проксі Player; підміна поля — неініціалізований тестовий CraftPlayer. Ці перевірки не моделюють підключений клієнт Minecraft, усі дії GUI, зовнішні інтеграції, справжню мережу проксі чи узгодження TLS із MySQL. `RuntimeProbe.jar` — допоміжний тестовий плагін, який не входить до встановлюваного плагіна та файлів випуску.

JAR Paper та образ контейнера Java зафіксовано за SHA-256. Мережа доступна лише на етапі підготовки залежностей Paper; плагін працює з `--network none`, без опублікованих портів і з новим каталогом даних. Випуск очікує успішного проходження цієї перевірки та збирань на обох ОС.

Відтворення після `gradlew build`, якщо встановлено Python 3 і Docker:

```sh
python tools/verify_paper.py --plugin build/libs/UltraPermissions-5.6.9.jar --probe build/runtime-test/RuntimeProbe.jar --work-dir build/paper-runtime --report-dir build/reports/runtime --accept-eula
```

Щоразу використовуйте новий робочий каталог. `--accept-eula` явно приймає [Minecraft EULA](https://aka.ms/MinecraftEULA) для тимчасового тестового сервера. Звіти містять хеш перевіреного плагіна та версії середовища. Перед оновленням створіть резервну копію даних сервера.
