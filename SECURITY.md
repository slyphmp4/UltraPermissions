# Security

Supported branch: main / 5.6.8-security.1.

For a vulnerability report, prefer this repository's private security advisory/reporting feature when available. Do not post production passwords, network keys or private player data in public issues. Include the affected version, configuration/topology conditions, impact and a minimal reproduction using test data.

See [security changes](docs/SECURITY-CHANGES.md) and [configuration](docs/CONFIGURATION.md). CI uses test doubles and does not certify every Minecraft/proxy/JDBC deployment.
