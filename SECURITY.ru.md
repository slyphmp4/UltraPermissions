# Безопасность

Поддерживаемая ветка/версия: `main` / `5.6.9`.

Для сообщения об уязвимости по возможности используйте приватные сообщения о безопасности этого репозитория. Не публикуйте рабочие пароли, сетевые ключи и личные данные игроков в открытых issues. Укажите затронутую версию, важные настройки и топологию сети, последствия проблемы и минимальный пример воспроизведения на тестовых данных.

См. [изменения безопасности](docs/SECURITY-CHANGES.ru.md) и [инструкцию настройки](docs/CONFIGURATION.ru.md). CI использует тестовые подмены объектов и не подтверждает безопасность любого развёртывания Minecraft/прокси/JDBC.
